오프라인 PDF 업무도구 사용 안내

1. 바탕화면의 “오프라인 PDF 업무도구”를 두 번 클릭합니다.
2. 왼쪽에서 원하는 작업을 선택합니다.
3. “파일 추가”를 눌러 처리할 파일을 선택합니다.
   Ctrl 또는 Shift 키를 누르면 여러 파일을 함께 선택할 수 있습니다.
4. 필요한 설정을 입력합니다.
   - 페이지를 비우면 전체 페이지입니다.
   - 1~3쪽과 5쪽: 1-3,5
   - 순서 변경: 페이지 추출·순서 변경 → 3,1,2
   - 합치기 순서: 파일을 선택한 후 “위로·아래로” 버튼
5. 저장할 로컬 폴더를 선택하고 “실행”을 누릅니다.
6. 완료되면 “결과 폴더 열기”에서 결과를 확인합니다.

원본 파일은 그대로 보관합니다. 새 결과 폴더가 별도로 만들어집니다.
여러 파일 중 하나라도 오류가 나면 그 작업 결과 전체가 취소됩니다.
오류 파일을 제외하고 다시 실행하세요.

암호 있는 PDF는 입력 암호를 넣으세요.
PDF를 이미지·TXT로 저장하면 원본의 암호 보호는 적용되지 않습니다.
PDF 수정은 전자서명 검증 상태에 영향을 줄 수 있습니다.

여백 자르기는 개인정보 삭제가 아닙니다.
영역 영구 삭제는 한 파일씩 처리하며 미리보기에서 마우스로 영역을 그립니다.
삭제한 결과를 검색·복사·텍스트 추출·이미지 확인으로 검수하세요.
같은 정보가 다른 페이지나 영역에 남아 있으면 추가로 지정해야 합니다.

OneDrive·Dropbox 등과 자동 동기화되지 않는 승인된 로컬 폴더에 저장하세요.
프로그램에는 인터넷 전송·로그인·자동 업데이트가 없습니다.
작업 중 전원이 꺼져 .offline-pdf- 임시폴더가 남았다면 삭제하세요.

프로그램이 열리지 않으면 파일을 임의로 삭제하지 말고 배포 담당자에게 문의하세요.
프로그램 버전과 오류 코드만 먼저 전달하고 실제 입주민 문서를 보내지 마세요.
