OfflinePDF 1.2 사용 안내

실행
- 설치형은 바탕화면의 “오프라인 PDF 업무도구”를 엽니다.
- 포터블은 압축을 해제한 폴더의 OfflinePDF.exe를 실행합니다.
- Python 설치, 인터넷 연결이나 로그인은 필요하지 않습니다.

기본 사용
1. 홈의 카드에서 필요한 도구를 선택합니다.
2. “파일 추가”를 누르거나 탐색기에서 파일을 끌어놓습니다.
3. 필요한 설정과 로컬 저장 폴더를 확인합니다.
4. 작업 실행 버튼을 누릅니다.
5. “결과 폴더 열기”에서 결과를 확인합니다.

페이지 정리
- PDF 하나를 추가하면 페이지별 썸네일이 나타납니다.
- 카드를 끌어 원하는 위치에 놓으면 순서가 바뀝니다.
- Ctrl·Shift 또는 체크 영역으로 여러 페이지를 선택해 삭제·회전합니다.
- “되돌리기” 또는 “처음 상태로”로 편집을 취소할 수 있습니다.
- 더블클릭 또는 “크게 보기”로 페이지를 확인합니다.
- “파일·저장 설정”에서 암호·저장 폴더를 지정합니다.
- “페이지 번호로 지정”에서는 3,1,2 또는 1,1,2처럼 입력할 수 있습니다.
- “정리한 PDF 저장”을 누르면 편집 상태를 새 파일로 저장합니다.
- 다른 PDF를 추가하기 전 기존 편집 내용을 저장하세요.

미리보기
- 기본은 “폭 맞춤”이며 긴 페이지는 세로로 스크롤합니다.
- “한 페이지 보기” 또는 “－ / ＋”로 배율을 조절합니다.
- “파일·설정으로”에서 작업 화면으로 돌아갑니다.

이어서 작업
- 완료 후 “결과로 다음 작업”을 누르면 결과 파일로 다른 작업을 이어갑니다.
- 예: PDF 합치기 → 용량 줄이기 → 페이지 삭제
- 원본과 각 단계의 결과는 각각 보관됩니다.
- 암호화된 결과는 다음 작업에서 입력 암호를 다시 넣어야 합니다.

저장과 문서 보호
- 원본은 덮어쓰지 않으며, PDF결과_날짜시간_식별자 폴더를 만듭니다.
- 여러 파일 중 하나에서 오류가 나면 그 작업 결과 전체가 취소됩니다.
- 이미지·TXT 출력에는 원본 PDF의 암호 보호가 적용되지 않습니다.
- PDF 수정은 기존 전자서명의 검증 상태에 영향을 줄 수 있습니다.
- OneDrive·Dropbox 등과 동기화되지 않는 로컬 폴더를 사용하세요.

영역 삭제
개인정보 삭제 불가
- 개인정보 비식별화나 개인정보 삭제를 보장하는 용도로 사용하지 마세요.
- 문서 전체의 개인정보를 자동으로 찾아 삭제하는 기능이 아닙니다.
- 여백 자르기도 개인정보 삭제 기능이 아니며, 가려진 데이터는 남습니다.
