OfflinePDF 사용 안내
소스 버전 0.8.9.3

배포본에 포함된 기능은 프로그램 상단의 버전과 해당 버전의 변경 기록을 기준으로 확인하세요.

시작하기

포터블 ZIP을 모두 압축 해제하고 폴더 안의 OfflinePDF.exe를 실행합니다.
EXE와 함께 들어 있는 폴더·파일을 그대로 유지하세요. 업데이트는 새 버전을 별도 폴더에 압축 해제해 사용합니다.
프로그램 제거는 실행을 종료한 뒤 해당 프로그램 폴더를 삭제하면 됩니다.

1. 파일 추가를 누르거나 PDF·이미지를 창으로 끌어놓습니다.
2. 시작 화면에 표시된 도구를 선택합니다. 창이 작으면 스크롤해 나머지 도구를 볼 수 있습니다.
3. 설정과 저장 폴더를 확인하고 실행합니다.
4. 결과 폴더 열기로 결과를 확인합니다.

왼쪽 파일 목록에서 파일을 선택·제거하거나 위아래로 이동할 수 있습니다.
도구를 바꿔도 파일 목록은 유지됩니다. 이미지는 선택한 작업 전에 PDF로 변환됩니다.
암호가 필요한 PDF는 입력 창에서 암호를 입력합니다. 암호 제거에는 소유자 암호가 필요합니다.

화면 설정

창 하단 설정에서 언어(한국어·English)와 테마(기본·다크모드)를 선택한 뒤 적용을 누릅니다.
문서 목록과 입력한 작업 옵션은 유지됩니다. 언어와 테마는 다음 실행에도 유지됩니다.
Windows에서는 %LOCALAPPDATA%\OfflinePDF\settings.json에 이 두 항목만 저장합니다.
파일을 실제로 창 위로 끌어오면 창 전체 테두리와 끌어놓기 안내가 표시됩니다.
파일 추가 버튼 위에 마우스만 올리는 경우 문구나 끌어놓기 안내가 바뀌지 않습니다.

저장과 연속 작업

원본은 덮어쓰지 않습니다. 선택한 저장 위치 아래 PDF결과_로 시작하는 새 폴더를 만듭니다.
여러 파일을 한 번에 처리하다 오류가 나거나 취소하면 해당 작업의 미완성 결과를 정리합니다.
완료 후 결과로 다음 작업을 누르면 방금 저장한 파일로 다른 작업을 이어갈 수 있습니다.
예: PDF병합 → 용량 압축 → 페이지 정리

페이지 지정과 미리보기

페이지 입력란이 비어 있으면 전체를 처리합니다.
  1-3,5 : 1~3쪽과 5쪽
  3-1   : 3쪽, 2쪽, 1쪽 순서

크게 미리보기에서 폭 맞춤·한 페이지·확대·축소를 사용할 수 있습니다.
뒤로가기는 미리보기 → 작업 설정 → 도구 선택 순서로 이동합니다.

PDF병합

목록의 위에서 아래 순서로 합칩니다. 파일 순서와 저장 파일 이름을 확인하세요.
서로 다른 암호의 PDF를 합칠 때는 결과에 사용할 새 암호를 지정합니다.

PDF 분할

페이지별로 나누기는 선택한 쪽을 각각의 PDF로 저장합니다.
N개 파일로 나누기는 만들 파일 수와 다음 파일들의 시작 쪽을 입력합니다.
예: 10쪽 문서에서 파일 수 3, 시작 쪽 5,8 → 1~4쪽 / 5~7쪽 / 8~10쪽
이 도구는 왼쪽에서 선택한 PDF 하나를 처리합니다.

페이지 정리

썸네일을 끌어 순서를 바꾸고, 선택한 페이지를 삭제하거나 회전합니다.
Ctrl·Shift로 여러 페이지를 선택할 수 있습니다. 더블클릭하면 크게 볼 수 있습니다.
되돌리기·초기화를 지원합니다. 정리한 PDF 저장을 누르면 편집 결과를 저장합니다.
다른 PDF로 선택을 바꾸기 전에 필요한 결과를 저장하세요.

PDF 모아찍기

A4 한 장에 1~64쪽을 배치합니다. 기본은 4쪽·세로·여백 0mm·간격 0mm입니다.
가로 칸 수가 0이면 자동 배치하며, 직접 입력하면 세로 칸 수가 자동 계산됩니다.
가로 우선·세로 우선 순서를 선택할 수 있습니다. 마지막 장의 남는 칸은 비워 둡니다.

전체 내용 유지: 원래 비율로 전체를 표시합니다. 칸과 원본 비율이 다르면 빈 공간이 생깁니다.
꽉 채우기 (잘림): 비율을 유지하며 중앙을 기준으로 가장자리를 가려 칸을 채웁니다.
원본 PDF 안에 이미 들어 있는 흰 여백은 자동 제거하지 않습니다.
꽉 채우기는 정보 영구 삭제 기능이 아닙니다.

미리보기에서 저장될 A4 배치를 확인할 수 있습니다. 여러 입력은 파일별로 저장합니다.
하나로 합쳐 모아찍기하려면 먼저 PDF병합을 실행하세요.
주석·양식은 보이는 모양으로 고정되며 링크·입력 필드의 동작은 유지되지 않습니다.
실제 종이 출력의 여백은 프린터의 무테 인쇄 지원 여부에 따라 다릅니다.

용량 압축

무손실: 이미지 화질을 바꾸지 않고 문서 데이터를 정리합니다.
선명하게: 이미지 최대 300 DPI, JPEG 품질 90
권장: 이미지 최대 150 DPI, JPEG 품질 75
작게: 이미지 최대 96 DPI, JPEG 품질 50

원본 구성에 따라 용량이 줄지 않거나 커질 수 있습니다.
강한 압축은 작은 글자와 사진을 흐리게 만들 수 있습니다.

이미지 변환

PDF → 이미지는 JPG·PNG·BMP·GIF·TIFF·WebP를 지원하며 페이지별로 저장합니다.
이미지 → PDF는 JPG·PNG·BMP·GIF·TIFF·WebP를 A4에 배치합니다. 아이폰 사진(HEIC)은 지원하지 않으니 휴대폰 설정에서 '호환성 우선'으로 찍거나 JPG로 변환해 주세요.
여러 프레임이 있는 이미지는 프레임별로 페이지를 만듭니다.
PDF를 이미지로 저장하면 원본 PDF의 암호 보호는 출력 이미지에 적용되지 않습니다.

문구·이미지 삽입과 쪽 번호

문구 또는 서명·직인 이미지를 선택하고 위치·크기·불투명도를 조절합니다.
움직이는 이미지나 여러 프레임 중에서는 첫 프레임을 사용합니다.
서명·직인 이미지 삽입은 인증서 기반 전자서명이 아닙니다.
쪽 번호는 선택한 페이지 순서대로 추가합니다.

여백 자르기·영역 삭제·부가정보 정리

여백 자르기는 페이지 가장자리를 가리며, 가려진 정보가 파일 안에 남습니다.
영역 삭제는 미리보기에서 지정한 부분의 내용을 제거합니다.
지정 영역 밖의 개인정보까지 자동으로 찾아 지우는 기능은 아닙니다.
저장한 파일을 열어 검색·복사와 확대 보기를 통해 삭제 결과를 확인하세요.
문서 부가정보 정리는 속성·첨부파일 등을 정리하며 본문의 개인정보를 자동 삭제하지 않습니다.

텍스트 추출·OCR

텍스트 추출은 PDF에 들어 있는 문자를 TXT로 저장합니다. 스캔 이미지는 OCR을 사용하세요.
OCR은 한국어·영어 또는 두 언어를 선택할 수 있습니다. 언어자료는 프로그램에 포함되어 있어 따로 준비할 필요가 없습니다.
인식 결과에는 오인식이 있을 수 있습니다. 검색·복사한 내용을 확인하세요.
TXT 출력에는 원본 PDF의 암호 보호가 적용되지 않습니다.

AI 업스케일

스캔 이미지를 2배·4배로 확대·보정합니다. CPU로 처리하며 모델은 배포본에 포함됩니다.
AI 비교 미리보기는 첫 번째 보정 가능 이미지의 중앙 부분을 실제 모델로 처리합니다.
이미지 한 장의 보정 결과가 4천만 픽셀을 넘으면 중단합니다. 배율이나 원본 해상도를 낮추세요.
투명·마스크·1비트 흑백 이미지와 일부 내장 이미지 형식은 보정하지 않습니다.
작은 글자·숫자·서명의 모양이 달라질 수 있으므로 원본과 대조하세요.

문제 해결

파일을 추가할 수 없음: PDF 또는 지원 이미지인지 확인하세요.
잠긴 파일: 왼쪽 목록에서 파일을 선택해 암호를 다시 입력하세요.
저장 경로 오류: OneDrive·네트워크 드라이브 대신 로컬 폴더를 선택하세요.
강제 종료 후 임시폴더가 남음: 프로그램을 종료한 상태에서 저장 위치의 .offline-pdf-로 시작하는 폴더를 확인하세요.
전자서명 문서: 내용을 수정하면 기존 서명의 검증 상태가 달라질 수 있습니다.

오류 제보: 소속 기관의 전산 담당자(이 프로그램을 배포한 담당 부서)에게 알려 주세요.
재현 순서, 프로그램 버전(프로그램 아래쪽 '정보'에서 확인)과 오류 문구를 적어 주세요.
인터넷 게시판이나 공개 사이트에는 업무 문서와 내부 정보를 올리지 마세요.
문서를 전달할 때는 개인정보와 내부 정보를 제거한 재현용 파일을 사용하세요.

파일당 목표·최대 용량

용량 압축에서 목표 용량을 선택하고 파일당 MB, 최소 이미지 DPI(72~300), 최소 JPEG 품질(30~95)을 입력합니다.
AI 업스케일에서는 '상세 옵션'을 열어 파일당 최대 용량에 MB를 입력합니다. 공란은 제한 없음이며, 최소 DPI·품질은 최대 용량을 입력했을 때만 사용합니다.
1 MB는 1,000,000바이트이며 파일별 최종 PDF(암호화 포함)에 적용합니다. 여러 파일의 합계 용량 제한이 아닙니다.
기본 최소값은 96 DPI·품질 50입니다. 상한 이하면 불필요하게 다시 압축하지 않습니다.
상한 초과 시 높은 DPI부터 JPEG 품질을 낮춰 보고, 여전히 크면 DPI도 낮춰 다시 시도합니다.
각 시도는 같은 기준 파일에서 시작하며, 이전 시도의 JPEG를 반복 압축하지 않습니다.
텍스트·도형은 이미지로 변환하지 않습니다. 보정된 이미지가 다시 축소·압축될 수 있으므로 결과를 확인하세요.
최소 DPI·품질까지 시도해도 목표에 도달하지 못하면 이번 작업의 결과 전체를 저장하지 않고 시도한 최소 용량을 알립니다.
목표 용량은 정확한 크기를 채우는 기능이 아니라 해당 용량 이하로 맞추는 기능입니다.
AI의 픽셀·메모리 제한은 별도입니다. 최대 MB를 입력해도 4배 확대의 큰 이미지 오류가 해제되지는 않습니다.

결과물 흰 빈 페이지 삭제

왼쪽 사이드바 아래의 '흰 빈 페이지 삭제'를 체크합니다. 프로그램을 켤 때마다 꺼진 상태로 시작하며, 켜져 있으면 실행 버튼 옆에 '빈 페이지 삭제 켜짐'이 표시됩니다. 텍스트 추출·PDF→이미지에는 적용되지 않습니다.
페이지 정리에서는 파일·저장 설정 창에서도 선택할 수 있습니다.
작업 처리 후 빈 페이지를 검사하고, 삭제 후 최종 용량을 확인합니다. 미리보기에는 이 저장 전 처리가 적용되지 않습니다.
문자·도형·링크·주석·양식이 없는 완전한 흰 페이지를 대상으로 합니다.
이미지는 원래 픽셀에서도 확인하므로 희미한 점이나 스캔 잡음이 있으면 보존합니다.
투명·인라인 이미지, 매우 큰 페이지나 이미지 등 확실히 검사할 수 없는 페이지는 보존합니다.
배경 도형만 있는 페이지나 OCR 숨은 문자가 있는 흰 스캔도 보존될 수 있습니다.
모든 페이지가 빈 페이지이면 저장을 중단합니다. 페이지별 분할도 빈 파일이 나오면 전체 작업을 중단하므로 옵션을 끄거나 먼저 빈 페이지를 정리하세요.
PDF 모아찍기는 배치가 끝난 A4 용지 전체를 검사하며, 개별 칸을 지우거나 다시 배치하지 않습니다.
완료 상태에 삭제한 페이지 수가 표시됩니다. 원본은 변경하지 않습니다.
