OfflinePDF 1.2 사용 안내

실행
- 설치형은 바탕화면의 “오프라인 PDF 업무도구”를 엽니다.
- 포터블은 압축을 해제한 폴더의 OfflinePDF.exe를 실행합니다.
- Python 설치, 인터넷 연결이나 로그인은 필요하지 않습니다.

기본 사용
1. 왼쪽 “파일 추가”를 누르거나 탐색기에서 파일을 끌어놓습니다.
2. 홈의 카드에서 도구를 선택합니다. 도구 선택 후 파일을 추가해도 됩니다.
3. 필요한 설정과 로컬 저장 폴더를 확인합니다.
4. 작업 실행 버튼을 누릅니다.
5. “결과 폴더 열기”에서 결과를 확인합니다.

파일 목록과 화면
- 파일 이름·페이지 수 또는 이미지 크기·용량을 왼쪽 사이드바에서 확인합니다.
- 도구를 바꿔도 파일 목록은 유지됩니다. 사용할 수 없는 형식은 표시되며 실행이 제한됩니다.
- “전체 도구 보기”를 누르면 18개 도구가 높이를 줄인 간략 카드로 바뀝니다.
- 창 크기에 맞춰 카드와 설정 항목이 자동 정렬됩니다. 최소 창 크기는 900×620입니다.
- 추가한 파일과 파일 수, 하단 알림이 강조되며 같은 알림이 반복되어도 다시 강조됩니다.
- 진행률·취소는 작업 중에, 결과 버튼은 완료 후에 표시됩니다.

PDF 나누기
- 페이지별 나누기: 선택한 페이지를 각각 별도 PDF로 저장합니다.
- N개 파일로 나누기: 파일 수 N과 다음 파일의 시작 쪽 N−1개를 입력합니다.
- 예: 10쪽 문서 / N=2 / 시작 쪽 5 → 1–4쪽, 5–10쪽
- 예: 10쪽 문서 / N=3 / 시작 쪽 5,8 → 1–4쪽, 5–7쪽, 8–10쪽
- 페이지 정리와 나누기는 왼쪽에서 선택한 PDF 한 개를 처리합니다.

이미지 변환
- PDF → 이미지: JPG(기본)·PNG·BMP·GIF·TIFF·WebP 중 저장 형식을 선택합니다.
- 이미지 → PDF: JPG·JPEG·PNG·BMP·GIF·TIF·TIFF·WebP·HEIC·HEIF를 추가할 수 있습니다.
- 여러 프레임이 있는 이미지는 프레임마다 한 쪽으로 변환합니다.
- 이미지 비율과 사진의 회전 정보를 반영하며, 투명한 부분은 흰색으로 처리합니다.
- HEIC·HEIF 읽기에 필요한 구성요소가 포함되어 별도 코덱 설치는 필요하지 않습니다.

페이지 정리
- PDF 하나를 추가하면 페이지별 썸네일이 나타납니다.
- 카드를 끌어 원하는 위치에 놓으면 순서가 바뀝니다.
- Ctrl·Shift 또는 체크 영역으로 여러 페이지를 선택해 삭제·회전합니다.
- “되돌리기” 또는 “초기화”로 편집을 취소할 수 있습니다.
- 더블클릭 또는 “크게 보기”로 페이지를 확인합니다.
- “설정”에서 암호를 지정하며 저장 폴더는 위쪽 고정 영역에서 선택합니다.
- 썸네일 크기 조절 막대로 화면에 표시할 페이지 수를 조절합니다.
- “페이지 번호로 지정”에서는 3,1,2 또는 1,1,2처럼 입력할 수 있습니다.
- “정리한 PDF 저장”을 누르면 편집 상태를 새 파일로 저장합니다.
- 다른 PDF를 추가하기 전 기존 편집 내용을 저장하세요.

미리보기
- 기본은 “폭 맞춤”이며 긴 페이지는 세로로 스크롤합니다.
- “한 페이지” 또는 “－ / ＋”로 배율을 조절합니다.
- “작업 설정”에서 설정이나 페이지 정리 화면으로 돌아갑니다.
- 문서 영역 안에서만 스크롤하고 파일 목록과 실행·알림 영역은 고정됩니다.

검색 가능한 PDF
- 한국어·영어를 선택하고 실행합니다. 언어자료는 배포본에 포함되어 있습니다.
- Windows의 한글 경로는 자동으로 보완하며 필요 시 언어자료만 영문 임시 경로에 준비합니다.
- PDF나 인식 문자를 해당 임시 경로에 복사하지 않습니다.
- OCR 결과에는 오인식이 있을 수 있습니다.

이어서 작업
- 완료 후 “결과로 다음 작업”을 누르면 결과 파일로 다른 작업을 이어갑니다.
- 예: PDF 합치기 → 용량 줄이기 → 페이지 삭제
- 원본과 각 단계의 결과는 각각 보관됩니다.
- 암호화된 결과는 다음 작업에서 입력 암호를 다시 넣어야 합니다.

저장과 문서 보호
- 원본은 덮어쓰지 않으며, PDF결과_날짜시간_식별자 폴더를 만듭니다.
- 여러 파일 중 하나에서 오류가 나면 그 작업 결과 전체가 취소됩니다.
- 이미지·TXT 출력에는 원본 PDF의 암호 보호가 적용되지 않습니다.
- PDF 수정은 기존 전자서명의 검증 상태에 영향을 줄 수 있습니다.
- OneDrive·Dropbox 등과 동기화되지 않는 로컬 폴더를 사용하세요.

영역 삭제
개인정보 삭제 불가
- 개인정보 비식별화나 개인정보 삭제를 보장하는 용도로 사용하지 마세요.
- 문서 전체의 개인정보를 자동으로 찾아 삭제하는 기능이 아닙니다.
- 여백 자르기도 개인정보 삭제 기능이 아니며, 가려진 데이터는 남습니다.
