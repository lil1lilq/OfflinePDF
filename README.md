# OfflinePDF

Windows에서 PDF를 병합·분할·편집하는 한국어 데스크톱 프로그램입니다.
문서 처리는 PC 안에서 이루어지며, 파일을 외부 변환 서버에 업로드하지 않습니다.

## 다운로드

[Releases에서 Windows용 프로그램 다운로드](https://github.com/lil1lilq/OfflinePDF/releases/latest)

| 파일 | 실행 방법 |
| --- | --- |
| `OfflinePDF-Windows-x64-portable.zip` | 압축을 풀고 폴더 안의 `OfflinePDF.exe` 실행 |

별도 설치 과정 없이 포터블 ZIP으로 제공합니다. Windows 10·11의 64비트 환경을 지원합니다. 배포본에는 실행에 필요한 구성요소가 포함되어 있어 Python을 별도로 설치할 필요가 없습니다.
포터블 버전은 실행파일과 함께 들어 있는 폴더를 그대로 유지해야 합니다.

현재 소스 버전은 **0.8.6**입니다. 다운로드 파일의 버전은 Releases에 표시된 버전을 확인하세요.
소스에 추가된 기능이나 수정 사항은 이전 배포본에 포함되지 않을 수 있습니다.

## 주요 기능

| 기능 | 내용 |
| --- | --- |
| PDF병합·분할 | 여러 파일 병합, 페이지별 분할, 시작 쪽을 지정한 분할 |
| 페이지 정리 | 썸네일을 끌어 순서 변경, 선택 페이지 삭제·회전 |
| PDF 모아찍기 | A4 한 장에 1~64쪽 배치, 방향·여백·간격 조절 |
| 용량 압축 | 무손실·선명하게·권장·작게, 파일당 목표 MB 설정 |
| PDF·이미지 변환 | PDF를 이미지로 저장하거나 이미지를 A4 PDF로 변환 |
| 암호 편집 | PDF 열기 암호 설정·제거 |
| 문구·이미지 삽입 | 문구, 서명·직인 이미지와 쪽 번호 삽입 |
| 여백 자르기·영역 삭제 | 페이지 가장자리 가리기, 지정 영역의 내용 삭제 |
| 텍스트 추출·OCR | 텍스트 저장, 스캔 문서의 한국어·영어 글자 인식 |
| AI 업스케일 | 스캔 이미지 2배·4배 확대·보정, 전후 부분 비교, 파일당 최대 MB 설정 |
| 문서 부가정보 정리 | 문서 속성·첨부파일 등 정리 |

PDF 저장 도구에서 **흰 빈 페이지 삭제**를 선택할 수 있습니다. 문자·도형·주석·양식이나 이미지 흔적이 있는 페이지는 보존합니다.
목표·최대 용량은 파일 하나당 상한이며, 최소 이미지 DPI·품질로도 맞출 수 없으면 해당 작업의 결과를 저장하지 않습니다. 용량 제한으로 AI 보정 이미지의 화질이 낮아질 수 있습니다.

이미지 입력은 JPG·PNG·BMP·GIF·TIFF·WebP·HEIC·HEIF 등을 지원합니다.
PDF의 이미지 출력은 JPG·PNG·BMP·GIF·TIFF·WebP를 지원합니다.
Word·Excel·PowerPoint·HWP 변환은 지원하지 않습니다.

## 사용 방법

1. **파일 추가**를 누르거나 탐색기에서 파일을 창으로 끌어놓습니다.
2. 도구를 선택합니다. **전체 도구 보기**에서 모든 기능을 확인할 수 있습니다.
3. 페이지 범위와 작업 설정, 저장 폴더를 지정하고 실행합니다.
4. **결과 폴더 열기**에서 저장한 파일을 확인합니다.

원본 파일은 덮어쓰지 않습니다. 결과는 선택한 저장 위치 아래 `PDF결과_…` 폴더에 저장됩니다.
완료 후 **결과로 다음 작업**을 선택하면 결과 파일로 다른 작업을 이어갈 수 있습니다.

페이지 입력란을 비우면 전체 페이지를 처리합니다. `1-3,5`는 1~3쪽과 5쪽, `3-1`은 역순입니다.
이미지를 추가하면 선택한 작업에 앞서 PDF로 자동 변환합니다.

자세한 조작 방법은 [사용 안내](USER_GUIDE_KO.txt)를 참고하세요.

## 문서 처리 시 확인할 점

- **여백 자르기**와 모아찍기의 **꽉 채우기**는 내용을 가리는 기능입니다. 가려진 정보는 문서 안에 남을 수 있습니다.
- **영역 삭제**는 지정한 부분에 적용됩니다. 문서 전체의 개인정보를 자동으로 찾아 지우는 기능은 아니므로 결과를 확인해야 합니다.
- OCR에는 오인식이 있을 수 있습니다. AI 보정은 작은 글자·숫자·서명의 모양을 바꿀 수 있어 원본과 대조가 필요합니다.
- 서명·직인 이미지를 넣는 기능은 인증서 기반 전자서명이 아닙니다. 기존 전자서명이 있는 PDF를 수정하면 서명 검증 상태가 달라질 수 있습니다.
- 네트워크 드라이브와 알려진 동기화 폴더는 사용이 제한됩니다. 작업 파일과 결과는 로컬 폴더에서 관리하세요.
