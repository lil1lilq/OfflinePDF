# OfflinePDF

문서를 외부 서버에 업로드하지 않고 PC에서 처리하는 오프라인 PDF 프로그램입니다.
개인정보나 내부 자료가 포함된 문서를 온라인 서비스에 전송할 필요가 없어, 외부 업로드에 따른 정보 유출 우려를 줄일 수 있습니다.
인터넷 연결과 로그인 없이 사용할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 버전 | 0.8.3 |
| 운영체제 | Windows 10·11, 64비트 |
| 지원 언어 | 한국어(한글) |
| OCR 언어 | 한국어·영어 |
| 라이선스 | AGPL-3.0-or-later |

## 다운로드와 실행

저장소의 **Releases**에서 Windows용 파일을 내려받습니다.

- **설치형**: `OfflinePDF-Setup-Windows-x64.exe`를 실행한 뒤 바탕화면의 **오프라인 PDF 업무도구**를 엽니다.
- **포터블**: `OfflinePDF-Windows-x64-portable.zip`을 압축 해제하고, 폴더 안의 `OfflinePDF.exe`를 실행합니다. 실행파일과 함께 들어 있는 폴더·파일을 유지해야 합니다.

Python이나 별도 PDF 프로그램을 설치할 필요가 없습니다.

## 기본 사용법

1. 왼쪽 **파일 추가**를 누르거나 탐색기에서 파일을 창에 끌어놓습니다. 도구를 먼저 선택해도 됩니다.
2. 필요한 도구를 선택합니다. **전체 도구 보기**를 누르면 16개 도구가 높이를 줄인 간략 카드로 표시됩니다.
3. 페이지, 회전 각도, 암호 등 필요한 설정과 저장 위치를 확인합니다.
4. 작업 실행 버튼을 누릅니다.
5. 완료되면 **결과 폴더 열기**에서 파일을 확인합니다.

원본은 덮어쓰지 않습니다. 결과는 선택한 저장 위치 아래 `PDF결과_날짜시간_식별자` 폴더에 저장합니다.
여러 파일을 처리하다 오류가 발생하면 해당 작업의 결과 전체를 취소합니다. 오류가 있는 파일을 제외하고 다시 실행할 수 있습니다.

| PDF 분할 | 페이지별 저장 또는 N개 파일로 나누기, 다음 파일의 시작 쪽 지정 |

### 영역 삭제 안내

선택한 영역만 영구 삭제됩니다. 저장 후 개인정보가 남아 있는지 확인하세요.

지정한 영역의 텍스트와 이미지 내용을 제거합니다. 문서 전체의 개인정보를 자동으로 찾아 삭제하는 기능은 아닙니다. 원본과 이전 작업 결과는 그대로 남습니다.

## PDF 모아찍기

**전체 도구 보기 → PDF 모아찍기**에서 A4 한 장에 여러 페이지를 배치합니다.
기본값은 한 장당 4쪽·세로·여백 0mm·간격 0mm·전체 내용 유지입니다.

- **한 장당 쪽수**: 1~64의 정수를 직접 입력합니다. 마지막 장의 남은 칸은 비워 둡니다.
- **A4 방향**: 세로 또는 가로를 선택합니다.
- **가로 칸 수**: 0은 자동 배치입니다. 첫 선택 페이지를 크게 표시할 수 있는 칸 수를 정합니다. 직접 입력하면 세로 칸 수는 쪽수에 맞게 계산됩니다.
- **배치 순서**: 가로 우선 또는 세로 우선입니다.
- **페이지**: 공란은 전체이며, `5-1,3,3`처럼 순서·반복을 지정할 수 있습니다.
- **여백·간격**: mm 단위로 설정합니다. 원본 페이지 안의 흰 여백은 자동 제거하지 않습니다.
- **전체 내용 유지**: 비율을 유지해 전체를 넣습니다. 원본과 칸의 비율이 다르면 빈 공간이 남습니다.
- **꽉 채우기 (잘림)**: 비율을 유지하며 중앙을 기준으로 가장자리를 잘라 칸을 채웁니다. 가려진 내용은 영구 삭제되지 않습니다.

미리보기에는 선택 문서의 실제 A4 배치가 표시됩니다. 이전·다음으로 결과 장을 넘길 수 있습니다.
여러 파일은 파일별로 별도의 PDF를 만듭니다. 합쳐서 배치하려면 PDF병합 후 결과로 다음 작업을 선택하세요.
텍스트·도형을 페이지 전체 이미지로 바꾸지 않고 배치합니다. 주석·양식은 보이는 모양으로 고정되며 링크·입력 필드의 상호작용은 유지하지 않습니다.
암호가 있는 입력은 기존 저장 규칙에 따라 결과 PDF에도 암호를 적용합니다. 원본은 변경하지 않습니다.
PDF 가장자리까지 배치해도 종이 출력 시 여백은 프린터의 무테 인쇄 지원 여부에 따라 다릅니다.

## 페이지 정리

왼쪽 파일 목록에서 PDF를 선택하면 각 페이지의 실제 썸네일이 나타납니다.
카드를 원하는 위치로 끌어놓으면 순서가 바뀌고, 파란 선으로 삽입 위치를 표시합니다.
카드의 원본 쪽 번호와 화면의 저장 순서를 구분해 확인할 수 있습니다.

- **다중 선택**: Ctrl·Shift를 누르고 클릭하거나 카드의 체크 영역을 누릅니다.
- **삭제·회전**: 선택한 페이지를 결과에서 제외하거나 오른쪽으로 90도씩 돌립니다.
- **되돌리기 / 초기화**: 이전 편집을 취소하거나 문서를 처음 불러온 상태로 복원합니다.
- **크게 보기**: 카드를 더블클릭하거나 **크게 보기**를 누릅니다.
- **설정**: 저장 폴더를 지정합니다. **페이지 번호로 지정**에서 `3,1,2`, `5-1`, `1,1,2`처럼 입력할 수도 있습니다.
- **정리한 PDF 저장**: 화면의 순서·삭제·회전 상태를 반영한 새 PDF를 만듭니다.

다른 PDF를 선택하면 편집할 문서가 바뀝니다. 기존 편집 내용은 저장한 뒤 선택을 바꾸세요.
썸네일 크기 조절 막대로 한 번에 볼 페이지 수를 바꿀 수 있습니다.

| 단축키 | 동작 |
| --- | --- |
| 방향키 | 페이지 선택 |
| Ctrl+A | 전체 선택 |
| Alt+왼쪽·오른쪽 | 선택한 페이지 이동 |
| Delete | 선택한 페이지 삭제 |
| Ctrl+Z | 되돌리기 |
| Enter | 크게 보기 |

## 큰 미리보기

기본값은 **폭 맞춤**입니다. 창의 가로 폭에 맞춰 페이지를 크게 표시하며, 긴 페이지는 세로로 스크롤합니다.
**한 페이지**는 페이지 전체가 보이도록 축소하고, **－ / ＋**는 배율을 조절합니다.
오른쪽 상단의 연한 파란색 **뒤로가기**를 누르면 미리보기를 열기 직전의 설정이나 페이지 정리 화면으로 돌아갑니다.
다시 누르면 도구 선택 화면으로 돌아갑니다. 뒤로가기 버튼은 상단 한 곳에만 있습니다.
문서 영역 안에서만 스크롤하며, 왼쪽 파일 목록과 아래 실행·알림 영역은 고정됩니다.

## 파일 목록과 화면

왼쪽 사이드바에서 파일 이름·페이지 수 또는 이미지 크기·용량을 확인할 수 있습니다.
도구 선택 화면에서도 파일을 확인하고 추가·제거·순서 변경할 수 있습니다.
도구를 바꿔도 파일은 유지됩니다. 모든 도구의 사이드바에 PDF와 지원 이미지를 섞어서 추가할 수 있습니다.
페이지 정리와 PDF 분할는 왼쪽에서 선택한 PDF 하나를 처리합니다.

도구 이름과 설명은 상단, 파일 목록은 왼쪽, 저장 위치와 실행 버튼은 하단에 표시합니다.
창 크기에 따라 카드 열 수와 작업 설정이 자동 정렬됩니다. 일반 카드에서는 자주 쓰는 6개 도구를, 간략 카드에서는 전체 16개 도구를 표시합니다.
전체 도구의 카드에 마우스를 올리거나 키보드로 초점을 맞추면 기능 설명이 표시됩니다.
전체 도구 보기·기본 카드로 보기 버튼에는 연한 테두리가 있으며, 처음 홈의 뒤로가기는 비활성화됩니다.
기본 창 크기는 1280×800이며 최소 창 크기는 900×620입니다. 파일 추가 시 해당 행과 파일 수가 강조되고, 하단 알림은 같은 문구로 갱신되어도 다시 강조됩니다.
진행률과 취소 버튼은 작업 중에, 결과 버튼은 완료 후에 표시됩니다.

## 이미지 자동 변환

사이드바에 PDF·JPG·PNG·BMP·GIF·TIF·TIFF·WebP·HEIC·HEIF를 섞어 추가할 수 있습니다.
이미지를 추가하면 **자동으로 PDF로 변경되어 작업이 수행됩니다**라는 알림이 표시됩니다.

1. 원하는 도구와 설정을 선택하고 실행합니다.
2. 이미지를 먼저 PDF로 변환한 뒤, 목록 순서대로 선택한 기능을 수행합니다. 여러 프레임은 각각 PDF 페이지가 됩니다.
3. 성공하면 사이드바의 이미지는 변환된 PDF로 대체됩니다. 변환본은 결과 폴더의 `입력PDF`에 보관합니다.

원본 이미지를 덮어쓰거나 삭제하지 않습니다. 실패·취소 시 변환본과 작업 결과를 함께 정리하고 기존 목록을 유지합니다.
AI 비교 미리보기에 사용하는 임시 변환본은 사이드바에 반영하지 않습니다.
**이미지 → PDF**의 A4 방향 설정은 이미지에 적용하고 함께 추가한 PDF의 원래 페이지 크기는 유지합니다.
파일 추가는 사이드바로 통합했으며, 목록이 길어질 때만 사이드바 스크롤이 나타납니다.

## N개 파일로 나누기

1. PDF를 선택하고 **PDF 분할 → N개 파일로 나누기**를 선택합니다.
2. 만들 파일 수 N과 다음 파일들의 시작 쪽 N−1개를 입력합니다. 여러 시작 쪽은 쉼표로 구분합니다.
3. 생성될 페이지 범위를 확인하고 실행합니다.

10쪽 문서에서 N=2, 시작 쪽 `5`는 **1–4쪽 / 5–10쪽**을 만듭니다.
N=3, 시작 쪽 `5,8`은 **1–4쪽 / 5–7쪽 / 8–10쪽**을 만듭니다.
시작 쪽은 2쪽부터 문서의 마지막 쪽 사이의 오름차순이며, 중복이나 빈 파일은 허용하지 않습니다.

## 결과로 다음 작업

완료 후 **결과로 다음 작업**을 누르고 도구를 선택하면 방금 만든 결과 파일이 자동으로 추가됩니다.

**PDF병합 → 용량 압축 → 페이지 정리**처럼 파일을 다시 찾지 않고 작업을 이어갈 수 있습니다.
원본과 각 단계의 결과는 각각 보관됩니다.

PDF와 이미지 결과 모두 다음 도구로 이어집니다. 이미지는 필요한 경우 PDF로 자동 변환합니다.
TXT 결과에는 후속 처리 기능이 없습니다. 같은 실행 중에는 결과 PDF의 암호도 이어서 사용합니다.

## PDF 암호 입력

암호가 필요한 파일에만 입력 팝업이 열립니다. 암호가 틀리면 같은 창에서 다시 입력할 수 있습니다.
취소한 파일은 **잠김**으로 표시되며, 목록에서 클릭하면 다시 입력할 수 있습니다.
파일마다 다른 암호를 사용할 수 있고, 도구를 바꿔도 다시 묻지 않습니다. 파일 제거·프로그램 종료 시 해당 입력 암호를 잊으며 디스크에 저장하지 않습니다.

**암호 편집**에서 **암호 설정 / 암호 제거**를 선택합니다. 설정 시 새 암호를 입력하고, 제거 시 소유자 암호가 필요합니다. **PDF병합·이미지 → PDF**에서는 **암호 추가**를 눌러 선택적으로 설정합니다.
서로 다른 암호의 PDF를 합칠 때는 결과에 사용할 새 암호를 지정합니다.

## 문구·이미지 삽입

삽입 종류에서 **문구 / 이미지**를 선택합니다. 문구에는 한글·영문을 입력하고 글자 크기를 지정합니다.
이미지는 서명·직인 등을 선택한 뒤 너비(pt)를 지정하며 원래 비율과 투명도를 유지합니다. 여러 프레임이 있는 파일은 첫 프레임만 사용합니다.
위치와 불투명도는 두 종류 모두 조절할 수 있습니다. 문구는 기본 가운데·불투명도 0.25, 이미지는 기본 오른쪽 아래·불투명도 1입니다.
위치는 왼쪽 위·가운데 위·오른쪽 위·가운데·왼쪽 아래·가운데 아래·오른쪽 아래 중 선택합니다.
인증서 기반 전자서명 기능은 아닙니다.

## 용량 압축

기본값은 **권장**입니다. 텍스트와 도형은 유지하고 문서 안의 이미지를 압축합니다.

| 수준 | 처리 |
| --- | --- |
| 무손실 | 이미지 화질 변경 없이 문서 데이터 정리 |
| 선명하게 | 높은 해상도의 이미지를 최대 300 DPI·JPEG 품질 90으로 조절 |
| 권장 | 높은 해상도의 이미지를 최대 150 DPI·JPEG 품질 75로 조절 |
| 작게 | 높은 해상도의 이미지를 최대 96 DPI·JPEG 품질 50으로 조절 |

이미지는 배치 해상도가 목표의 1.2배를 넘을 때 축소하고, 압축 가능한 이미지는 선택한 품질로 다시 저장합니다. 1비트 흑백 이미지는 그대로 유지합니다.
문서에 따라 용량이 줄지 않거나 커질 수 있습니다. 강한 압축은 작은 글자와 사진을 흐리게 만들 수 있습니다.

## AI 업스케일

확대 배율은 **2배**가 기본이며 **4배**도 선택할 수 있습니다. 경량 AI 모델을 배포본에 포함해 CPU에서 실행하며, 별도 모델 다운로드·그래픽카드·로그인이 필요하지 않습니다.

**AI 비교 미리보기**는 선택 문서의 첫 번째 보정 가능 이미지 중앙 영역을 실제 모델로 처리해 원본 확대와 나란히 보여줍니다. 상단 **뒤로가기**로 직전 화면으로 돌아가면 비교용 파일을 정리합니다.
전체 작업을 실행하면 목록의 PDF를 각각 보정합니다. 원래 페이지 크기와 텍스트·검색용 텍스트·도형은 유지합니다.

- 불투명한 16×16픽셀 이상 컬러·회색 내장 이미지를 처리합니다. 투명·마스크·1비트 흑백 이미지와 인라인 이미지는 제외합니다.
- AI가 작은 글자·숫자·서명 모양을 바꿀 수 있습니다. 원본과 대조하고 보정 결과를 원본 증빙으로 간주하지 마세요.
- 확대는 파일 크기와 처리 시간을 늘릴 수 있으며, CPU·페이지 수·해상도에 따라 오래 걸릴 수 있습니다.
- 이미지 한 장의 결과가 4천만 픽셀을 넘으면 중단합니다. 4배에서 제한되는 문서는 2배를 선택하세요.

## 이미지 변환

**PDF → 이미지**에서 저장 형식을 선택합니다. 기본값은 JPG이며, 페이지마다 이미지 파일 하나를 만듭니다.
TIFF를 선택해도 페이지별 파일로 저장합니다. HEIC·HEIF로 내보내는 기능은 제공하지 않습니다.

**이미지 → PDF**는 여러 형식을 섞어 추가할 수 있습니다. 파일 목록 순서대로 A4 페이지에 비율을 유지해 배치하며 세로·가로 방향을 선택할 수 있습니다.
여러 프레임이 있는 GIF·TIFF·WebP 등은 프레임 순서대로 한 쪽씩 저장합니다. 애니메이션의 움직임과 재생 시간은 PDF에 적용되지 않습니다.
사진의 회전 정보를 반영하고 투명한 부분은 흰색으로 처리합니다.
HEIC·HEIF 처리 구성요소는 배포본에 포함되어 별도의 Windows 확장 프로그램을 설치하지 않아도 됩니다.

## 스캔 PDF 글자 인식(OCR)

**스캔 PDF 글자 인식(OCR)**에서 한국어·영어 또는 두 언어를 선택합니다. 언어자료는 배포본에 포함되어 인터넷 연결 없이 처리합니다.
Windows에서 프로그램 경로에 한글이 있으면 OCR이 읽을 수 있는 경로를 자동으로 준비합니다. 필요한 경우 언어자료만 로컬 영문 임시 경로에 복사하며 PDF와 인식한 문자는 이 경로에 복사하지 않습니다.
임시 경로를 만들 수 없는 환경에서는 원인을 안내합니다. OCR 결과에는 오인식이 있을 수 있으므로 검색·복사 결과를 확인하세요.

## 문서 처리와 저장

- 일반 실행에는 문서의 외부 업로드, 로그인, 자동 업데이트, 사용기록 수집 기능이 없습니다. Python 소켓 차단은 보조 방어이며 OS 샌드박스는 아닙니다.
- 배포 검증은 합성 문서를 사용해 Windows 방화벽 차단 상태의 처리와 해당 실행파일의 연결 이벤트를 검사합니다. 검증 절차·범위는 BUILDING.md에 있습니다.
- OneDrive·Dropbox 등과 동기화되지 않는 로컬 폴더를 사용하세요. 알려진 동기화 경로와 네트워크 경로는 제한되지만, 모든 동기화 도구를 자동으로 판별하지는 못합니다.
- 암호화된 PDF를 수정하면 입력 암호 또는 새로 지정한 암호를 결과 PDF에도 적용합니다. 이미지·TXT 출력과 암호 해제 결과에는 암호가 적용되지 않습니다.
- 문서를 수정하면 기존 전자서명의 검증 상태가 달라질 수 있습니다.
- 여백 자르기는 내용을 가리는 기능입니다. 가려진 데이터는 문서에 남아 있습니다.
- 문서 구성에 따라 압축 후 용량이 줄지 않을 수 있습니다. OCR 결과에는 오인식이 있을 수 있습니다.
- 작업 중 강제 종료되면 저장 위치에 `.offline-pdf-` 임시폴더가 남을 수 있습니다. 프로그램을 종료한 상태에서 확인한 뒤 삭제할 수 있습니다.

Office·HWP 변환, PDF/A 변환, PDF 비교, 스캐너 직접 제어와 인증서 전자서명은 지원하지 않습니다.
