# OfflinePDF

문서를 외부 서버에 업로드하지 않고 PC에서 처리하는 오프라인 PDF 프로그램입니다.
개인정보나 내부 자료가 포함된 문서를 온라인 서비스에 전송할 필요가 없어, 외부 업로드에 따른 정보 유출 우려를 줄일 수 있습니다.
인터넷 연결과 로그인 없이 사용할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 버전 | 1.2 |
| 운영체제 | Windows 10·11, 64비트 |
| 지원 언어 | 한국어(한글) |
| OCR 언어 | 한국어·영어 |
| 라이선스 | AGPL-3.0-or-later |

## 다운로드와 실행

저장소의 **Releases**에서 Windows용 파일을 내려받습니다.

- **설치형**: `OfflinePDF-Setup-Windows-x64.exe`를 실행한 뒤 바탕화면의 **오프라인 PDF 업무도구**를 엽니다.
- **포터블**: `OfflinePDF-Windows-x64-portable.zip`을 압축 해제하고, 폴더 안의 `OfflinePDF.exe`를 실행합니다. 실행파일과 함께 들어 있는 폴더·파일을 유지해야 합니다.

Python이나 별도 PDF 프로그램을 설치할 필요가 없습니다.

## 기본 사용법

1. 왼쪽 **파일 추가**를 누르거나 탐색기에서 파일을 창에 끌어놓습니다. 도구를 먼저 선택해도 됩니다.
2. 필요한 도구를 선택합니다. **전체 도구 보기**를 누르면 18개 도구가 높이를 줄인 간략 카드로 표시됩니다.
3. 페이지, 회전 각도, 암호 등 필요한 설정과 저장 위치를 확인합니다.
4. 작업 실행 버튼을 누릅니다.
5. 완료되면 **결과 폴더 열기**에서 파일을 확인합니다.

원본은 덮어쓰지 않습니다. 결과는 선택한 저장 위치 아래 `PDF결과_날짜시간_식별자` 폴더에 저장합니다.
여러 파일을 처리하다 오류가 발생하면 해당 작업의 결과 전체를 취소합니다. 오류가 있는 파일을 제외하고 다시 실행할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| PDF 합치기 | 여러 PDF를 파일 목록 순서대로 하나로 합치기 |
| PDF 나누기 | 페이지별 저장 또는 N개 파일로 나누기, 다음 파일의 시작 쪽 지정 |
| 페이지 정리 | 썸네일 드래그로 재배열, 다중 선택 삭제·회전, 되돌리기 |
| 페이지 삭제·회전 | 지정한 페이지 삭제 또는 90·180·270도 회전 |
| 용량 줄이기 | 불필요한 데이터 정리와 무손실 압축 |
| PDF → 이미지 | JPG(기본)·PNG·BMP·GIF·TIFF·WebP 중 선택해 저장, 72~300 DPI 지정 |
| 이미지 → PDF | JPG·JPEG·PNG·BMP·GIF·TIF·TIFF·WebP·HEIC·HEIF를 A4 PDF로 만들기 |
| 암호 설정·해제 | AES-256 암호 설정, 소유자 암호를 이용한 암호 해제 |
| 워터마크·쪽 번호 | 한글·영문 문구 또는 페이지 번호 추가 |
| 서명·직인 이미지 | 문서에 서명이나 직인 이미지 넣기 |
| 여백 자르기 | 네 방향의 여백을 같은 크기로 가리기 |
| 텍스트 추출 | PDF의 문자를 UTF-8 TXT로 저장 |
| 영역 영구 삭제 | 미리보기에서 지정한 영역 처리. 아래 안내 확인 |
| 문서 부가정보 정리 | 문서 속성·첨부파일·JavaScript 등 정리 |
| 검색 가능한 PDF | 스캔 문서의 한국어·영어 글자를 OCR로 인식 |

### 영역 삭제 안내

![개인정보 삭제 불가](assets/redaction-warning.svg)

영역 삭제를 개인정보 비식별화나 개인정보 삭제를 보장하는 용도로 사용하지 마세요.
지정한 영역을 처리하는 기능이며, 문서 전체의 개인정보를 자동으로 찾아 삭제하지 않습니다.

## 페이지 정리

왼쪽 파일 목록에서 PDF를 선택하면 각 페이지의 실제 썸네일이 나타납니다.
카드를 원하는 위치로 끌어놓으면 순서가 바뀌고, 파란 선으로 삽입 위치를 표시합니다.
카드의 원본 쪽 번호와 화면의 저장 순서를 구분해 확인할 수 있습니다.

- **다중 선택**: Ctrl·Shift를 누르고 클릭하거나 카드의 체크 영역을 누릅니다.
- **삭제·회전**: 선택한 페이지를 결과에서 제외하거나 오른쪽으로 90도씩 돌립니다.
- **되돌리기 / 처음 상태로**: 이전 편집을 취소하거나 문서를 처음 불러온 상태로 복원합니다.
- **크게 보기**: 카드를 더블클릭하거나 **크게 보기**를 누릅니다.
- **파일·저장 설정**: 입력 암호와 저장 폴더를 지정합니다. **페이지 번호로 지정**에서 `3,1,2`, `5-1`, `1,1,2`처럼 입력할 수도 있습니다.
- **정리한 PDF 저장**: 화면의 순서·삭제·회전 상태를 반영한 새 PDF를 만듭니다.

다른 PDF를 선택하면 편집할 문서가 바뀝니다. 기존 편집 내용은 저장한 뒤 선택을 바꾸세요.
썸네일 크기 조절 막대로 한 번에 볼 페이지 수를 바꿀 수 있습니다.

| 단축키 | 동작 |
| --- | --- |
| 방향키 | 페이지 선택 |
| Ctrl+A | 전체 선택 |
| Alt+왼쪽·오른쪽 | 선택한 페이지 이동 |
| Delete | 선택한 페이지 삭제 |
| Ctrl+Z | 되돌리기 |
| Enter | 크게 보기 |

## 큰 미리보기

기본값은 **폭 맞춤**입니다. 창의 가로 폭에 맞춰 페이지를 크게 표시하며, 긴 페이지는 세로로 스크롤합니다.
**한 페이지 보기**는 페이지 전체가 보이도록 축소하고, **－ / ＋**는 배율을 조절합니다.
**작업 설정**을 누르면 설정이나 페이지 정리 화면으로 돌아갑니다.
문서 영역 안에서만 스크롤하며, 왼쪽 파일 목록과 아래 실행·알림 영역은 고정됩니다.

## 파일 목록과 화면

왼쪽 사이드바에서 파일 이름·페이지 수 또는 이미지 크기·용량을 확인할 수 있습니다.
도구 선택 화면에서도 파일을 확인하고 추가·제거·순서 변경할 수 있습니다.
도구를 바꿔도 파일은 유지되며, 사용할 수 없는 형식은 목록에 표시됩니다. 실행할 때는 해당 파일을 제거하거나 맞는 도구를 선택하세요.
페이지 정리와 PDF 나누기는 왼쪽에서 선택한 PDF 하나를 처리합니다.

창 크기에 따라 카드 열 수와 작업 설정이 자동 정렬됩니다. 일반 카드에서는 자주 쓰는 6개 도구를, 간략 카드에서는 전체 18개 도구를 표시합니다.
기본 창 크기는 1280×800이며 최소 창 크기는 900×620입니다. 파일 추가 시 해당 행과 파일 수가 강조되고, 하단 알림은 같은 문구로 갱신되어도 다시 강조됩니다.
진행률과 취소 버튼은 작업 중에, 결과 버튼은 완료 후에 표시됩니다.

## N개 파일로 나누기

1. PDF를 선택하고 **PDF 나누기 → N개 파일로 나누기**를 선택합니다.
2. 만들 파일 수 N과 다음 파일들의 시작 쪽 N−1개를 입력합니다. 여러 시작 쪽은 쉼표로 구분합니다.
3. 생성될 페이지 범위를 확인하고 실행합니다.

10쪽 문서에서 N=2, 시작 쪽 `5`는 **1–4쪽 / 5–10쪽**을 만듭니다.
N=3, 시작 쪽 `5,8`은 **1–4쪽 / 5–7쪽 / 8–10쪽**을 만듭니다.
시작 쪽은 2쪽부터 문서의 마지막 쪽 사이의 오름차순이며, 중복이나 빈 파일은 허용하지 않습니다.

## 결과로 다음 작업

완료 후 **결과로 다음 작업**을 누르고 도구를 선택하면 방금 만든 결과 파일이 자동으로 추가됩니다.

**PDF 합치기 → 용량 줄이기 → 페이지 삭제**처럼 파일을 다시 찾지 않고 작업을 이어갈 수 있습니다.
원본과 각 단계의 결과는 각각 보관됩니다.

PDF 결과는 PDF용 도구로, 이미지 결과는 **이미지 → PDF**로 이어집니다.
TXT 결과에는 후속 처리 기능이 없습니다. 암호화된 결과는 다음 작업에서 입력 암호를 다시 넣어야 합니다.

## 이미지 변환

**PDF → 이미지**에서 저장 형식을 선택합니다. 기본값은 JPG이며, 페이지마다 이미지 파일 하나를 만듭니다.
TIFF를 선택해도 페이지별 파일로 저장합니다. HEIC·HEIF로 내보내는 기능은 제공하지 않습니다.

**이미지 → PDF**는 여러 형식을 섞어 추가할 수 있습니다. 파일 목록 순서대로 A4 페이지에 비율을 유지해 배치하며 세로·가로 방향을 선택할 수 있습니다.
여러 프레임이 있는 GIF·TIFF·WebP 등은 프레임 순서대로 한 쪽씩 저장합니다. 애니메이션의 움직임과 재생 시간은 PDF에 적용되지 않습니다.
사진의 회전 정보를 반영하고 투명한 부분은 흰색으로 처리합니다.
HEIC·HEIF 처리 구성요소는 배포본에 포함되어 별도의 Windows 확장 프로그램을 설치하지 않아도 됩니다.

## 검색 가능한 PDF

**검색 가능한 PDF**에서 한국어·영어 또는 두 언어를 선택합니다. 언어자료는 배포본에 포함되어 인터넷 연결 없이 처리합니다.
Windows에서 프로그램 경로에 한글이 있으면 OCR이 읽을 수 있는 경로를 자동으로 준비합니다. 필요한 경우 언어자료만 로컬 영문 임시 경로에 복사하며 PDF와 인식한 문자는 이 경로에 복사하지 않습니다.
임시 경로를 만들 수 없는 환경에서는 원인을 안내합니다. OCR 결과에는 오인식이 있을 수 있으므로 검색·복사 결과를 확인하세요.

## 문서 처리와 저장

- 문서의 외부 업로드, 로그인, 자동 업데이트, 사용기록 수집 기능이 없습니다.
- OneDrive·Dropbox 등과 동기화되지 않는 로컬 폴더를 사용하세요. 알려진 동기화 경로와 네트워크 경로는 제한되지만, 모든 동기화 도구를 자동으로 판별하지는 못합니다.
- 암호화된 PDF를 수정하면 입력 암호 또는 새로 지정한 암호를 결과 PDF에도 적용합니다. 이미지·TXT 출력과 암호 해제 결과에는 암호가 적용되지 않습니다.
- 문서를 수정하면 기존 전자서명의 검증 상태가 달라질 수 있습니다.
- 여백 자르기는 내용을 가리는 기능입니다. 가려진 데이터는 문서에 남아 있습니다.
- 문서 구성에 따라 압축 후 용량이 줄지 않을 수 있습니다. OCR 결과에는 오인식이 있을 수 있습니다.
- 작업 중 강제 종료되면 저장 위치에 `.offline-pdf-` 임시폴더가 남을 수 있습니다. 프로그램을 종료한 상태에서 확인한 뒤 삭제할 수 있습니다.

Office·HWP 변환, PDF/A 변환, PDF 비교, 스캐너 직접 제어와 인증서 전자서명은 지원하지 않습니다.
