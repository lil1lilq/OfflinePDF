# OfflinePDF

Windows 64비트용 오프라인 PDF 편집 프로그램입니다.  
PyMuPDF와 Python Tkinter를 사용하며, 모든 문서 작업은 사용자 PC에서 처리합니다.

- **버전:** 0.1.0
- **운영체제:** Windows x64
- **라이선스:** AGPL-3.0-or-later

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| PDF 병합 | 여러 PDF를 목록 순서대로 합치기 |
| PDF 분할 | 지정한 페이지마다 별도 파일 생성 |
| 페이지 편집 | 추출, 순서 변경, 복제, 삭제, 회전 |
| PDF 압축 | 미사용 객체 정리 및 무손실 압축 |
| 이미지 변환 | PDF ↔ PNG·JPG |
| 암호 설정·해제 | AES-256 암호화 및 소유자 암호를 통한 해제 |
| 워터마크 | 한글·영문 문구 삽입 |
| 쪽 번호 | 시작 번호를 지정해 페이지 번호 삽입 |
| 서명·직인 | 이미지 파일 삽입 |
| 여백 자르기 | 페이지의 표시 영역 조정 |
| 텍스트 추출 | PDF 문자를 TXT로 저장 |
| 영역 영구 삭제 | 미리보기에서 지정한 영역의 내용 삭제 |
| 부가정보 정리 | 문서 속성, 첨부파일, JavaScript 등 정리 |
| OCR | 한국어·영어 검색 가능한 PDF 생성 |

Word·Excel·PowerPoint·HWP 변환, PDF/A 변환, 인증서 전자서명은 지원하지 않습니다.

## 설치 및 실행

### 설치형

`OfflinePDF-Setup-Windows-x64.exe`를 실행해 설치한 뒤, 바탕화면의 **오프라인 PDF 업무도구** 아이콘으로 실행합니다.

### 압축 실행형

`OfflinePDF-Windows-x64-portable.zip`의 압축을 풀고 `OfflinePDF.exe`를 실행합니다. 실행파일과 함께 제공된 폴더 구성을 유지해야 합니다.

빌드된 프로그램은 Python 설치나 인터넷 연결 없이 사용할 수 있습니다.

## 사용 방법

1. 왼쪽 메뉴에서 작업을 선택합니다.
2. **파일 추가**에서 처리할 파일을 선택합니다.
3. 페이지 범위와 작업 옵션을 설정합니다.
4. 결과를 저장할 로컬 폴더를 선택합니다.
5. **실행**을 누르고, 완료 후 **결과 폴더 열기**에서 확인합니다.

여러 파일은 `Ctrl` 또는 `Shift` 키로 선택할 수 있습니다.  
합칠 파일의 순서는 **위로**, **아래로** 버튼으로 변경합니다.

### 페이지 입력 예시

| 작업 | 입력 |
| --- | --- |
| 전체 페이지 | 입력란 비우기 |
| 1~3쪽과 5쪽 | `1-3,5` |
| 역순 추출 | `5-1` |
| 순서 변경 및 복제 | `3,1,1,2` |

원본은 덮어쓰지 않습니다. 결과는 지정한 저장 위치에 새 폴더로 생성됩니다.

여러 파일을 한 번에 처리하다 오류가 발생하면 해당 작업 전체 결과가 취소됩니다. 오류가 있는 파일을 제외한 뒤 다시 실행합니다.

## 암호 처리

- 암호화된 PDF는 입력 암호가 필요합니다.
- 일반 PDF 수정 작업에서는 입력 암호 또는 새로 지정한 암호로 결과 PDF도 암호화합니다.
- 암호 해제에는 소유자 암호가 필요합니다.
- TXT와 이미지로 추출한 결과에는 PDF의 암호 보호가 적용되지 않습니다.
- 입력 암호가 서로 다른 PDF는 개별 처리해야 합니다.

## 영역 영구 삭제

**영역 영구 삭제**를 선택하고 미리보기에서 마우스로 삭제할 영역을 지정합니다.

한 번에 PDF 한 개를 처리하며, 지정 영역의 내용과 문서의 첨부파일·양식 필드·주석·링크·메타데이터를 정리합니다.

- 동일한 정보가 다른 페이지나 영역에 있으면 각각 지정해야 합니다.
- 자르기가 적용된 PDF는 지원하지 않습니다. 자르기 전 원본을 사용합니다.
- 삭제 결과는 검색·복사·텍스트 추출과 이미지 확인으로 검수해야 합니다.
- 자동 개인정보 탐지는 지원하지 않습니다.

**여백 자르기**는 표시 영역만 변경하므로 개인정보 삭제 용도로 사용할 수 없습니다.

## OCR

한국어와 영어 인식에 필요한 언어자료를 포함합니다. 실행 중 언어자료를 추가로 다운로드하지 않습니다.

스캔 페이지를 이미지로 렌더링한 뒤 문자층을 추가하는 방식입니다. 기존 링크·양식·책갈피 구조는 유지되지 않습니다.

원본 해상도와 글자 상태에 따라 오인식이 발생할 수 있습니다.

언어자료의 출처와 SHA256은 [`tessdata/models.json`](tessdata/models.json)에 기록되어 있습니다.

## 문서와 저장 위치

외부 서버 전송, 사용기록 수집, 자동 업데이트 기능은 없습니다. 문서 내용과 비밀번호를 디스크 로그에 기록하지 않습니다.

UNC 경로, Windows 네트워크 드라이브, 알려진 동기화 폴더는 차단합니다. 모든 동기화 경로를 판별할 수는 없으므로 OneDrive·Dropbox 등과 연결되지 않은 로컬 폴더를 사용해야 합니다.

작업 중간 파일은 저장 위치의 `.offline-pdf-` 임시폴더에 생성됩니다. 정상 종료·실패·취소 시 정리하며, 강제 종료나 전원 차단으로 남은 임시폴더는 직접 삭제해야 합니다.

## Windows 실행파일 빌드

### GitHub Actions

1. 프로젝트 파일 전체를 저장소 루트에 올립니다. `.github` 폴더도 포함합니다.
2. **Actions**에서 **Build Windows x64**를 선택합니다.
3. **Run workflow**를 실행합니다.
4. 완료 후 **Artifacts**의 **OfflinePDF-Windows-x64**를 내려받습니다.

| 빌드 결과 | 용도 |
| --- | --- |
| `OfflinePDF-Setup-Windows-x64.exe` | 설치형 |
| `OfflinePDF-Windows-x64-portable.zip` | 압축 실행형 |
| `SHA256SUMS.txt` | 파일 검증값 |

빌드 과정에서는 패키지 다운로드를 위해 인터넷 연결이 필요합니다. 완성된 프로그램은 오프라인으로 실행됩니다.

### 직접 빌드

필요 환경:

- Windows x64
- Python 3.12 x64
- Inno Setup 6.x

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
powershell -NoProfile -ExecutionPolicy Bypass -File packaging\build_windows.ps1 -Python .\.venv\Scripts\python.exe
```

자동 시험을 통과하면 `release` 폴더에 배포 파일이 생성됩니다. 코드서명 인증서는 포함하지 않습니다.

## 소스 실행 및 시험

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python main.py
```

검증 환경은 Python 3.12와 PyMuPDF 1.26.6입니다. 처리 엔진 및 GUI 자동 시험 24건을 통과했습니다.

Windows 실행파일과 설치파일의 실제 실행 검증은 별도로 필요합니다. 검증 범위와 미확인 항목은 [`TEST_REPORT.md`](TEST_REPORT.md)에 정리되어 있습니다.
